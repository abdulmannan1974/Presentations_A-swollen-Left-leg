The HTML file is self-contained, with embedded sound effects, and works offline after download. Open it in Edge, Chrome or Safari. Arrows/Space advance reveals, F opens fullscreen, S opens presenter view, N shows notes, M mutes/unmutes, and O opens the overview.

The deck contains 21 main slides paced for 15 minutes, plus two reference slides. It uses a light theme and includes the proximal DVT progression, anticoagulation and fibrinolysis animation, and lupus anticoagulant interference illustration. A clap accompanies “One job done”; glass shatters at “None”.

The returning case is fictional. Sources and clinical editing notes are included. This is teaching material, not a replacement for local clinical pathways.
